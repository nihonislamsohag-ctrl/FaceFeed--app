FotoFilm Android App

অ্যান্ড্রয়েড অ্যাপ প্যাকেজ (Kotlin/Compose • APK: ১২০–১২৬ MB • AAB: ~৭৬–৮০ MB)

নতুন FotoFilm অ্যাপের Debug APK ফাইলের সাইজ প্রায় ১২২ MB (১২০–১২৬ MB) এবং AAB ফাইলের সাইজ প্রায় ৭৬–৮০ MB। নিচের নির্দেশনা অনুযায়ী ফোনে ডাউনলোড ও ইনস্টল করুন।

📱 কীভাবে নতুন APK ও AAB ডাউনলোড করবেন:

  1. Google AI Studio স্ক্রিনের Settings / Export ➜ Generate APK / AAB অপশন থেকে সরাসরি app-debug.apk (১২০–১২৬ MB) বা app-debug.aab (~৭৬–৮০ MB) ডাউনলোড করুন।
  2. অথবা GitHub-এ Push করার পর আপনার রিপোজিটরির Releases ➜ Assets থেকে FotoFilm.apk (১২০–১২৬ MB) ও FotoFilm.aab (~৭৬–৮০ MB) ডাউনলোড করুন।
  3. ফোনের Downloads ফোল্ডার থেকে APK ফাইলটি চাপ দিয়ে Install করুন।

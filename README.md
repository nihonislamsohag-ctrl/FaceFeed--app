# FotoFilm - Android Social Networking App 🚀

**FotoFilm** (আগে FaceFeed) একটি আধুনিক সোশ্যাল মিডিয়া, চ্যাট, ভিডিও/অডিও কলিং এবং কমিউনিটি অ্যান্ড্রয়েড অ্যাপ্লিকেশন।

---

## 📥 নতুন APK ও AAB ডাউনলোড করুন (APK: ১২০–১২৬ MB • AAB: ~৭৬–৮০ MB):

আপনার ফোনে নতুন **FotoFilm** অ্যাপটি (গ্রিন ভেরিফাইড ব্যাজ, ChatFilm, ফিদা এআই, লাইভ আড্ডা ও লুডু কিং গ্রুপসহ) ইনস্টল করতে অথবা **App Bundle (.aab)** নিতে নিচের **GitHub Releases** লিংকে ক্লিক করে সরাসরি ডাউনলোড করুন:

👉 **[FotoFilm.apk সরাসরি ডাউনলোড করুন (১২২ MB / ১২০–১২৬ MB)](../../releases/latest/download/FotoFilm.apk)**

👉 **[FotoFilm.aab সরাসরি ডাউনলোড করুন (~৭৬–৮০ MB)](../../releases/latest/download/FotoFilm.aab)**

👉 **[সব রিলিজ দেখুন (GitHub Releases পেজ)](../../releases)**

*(দ্রষ্টব্য: কোড GitHub-এ Push করার ৩–৫ মিনিট পর GitHub Actions স্বয়ংক্রিয়ভাবে নতুন **FotoFilm.apk (১২০–১২৬ MB)** ও **FotoFilm.aab (~৭৬–৮০ MB)** তৈরি করে **Releases ➜ Assets** পেজে আপলোড করে দেয়। এছাড়া Google AI Studio-র **Settings ➜ Generate APK/AAB** থেকেও নতুন বিল্ড নামানো যায়।)*

*(প্লে স্টোরে আপলোডের জন্য Signed Release AAB চাইলে রিপোজিটরির Settings ➜ Secrets and variables ➜ Actions-এ `UPLOAD_KEYSTORE_BASE64`, `STORE_PASSWORD` ও `KEY_PASSWORD` যোগ করলে `FotoFilm-PlayStore-Signed.aab` ও তৈরি হয়ে Assets-এ যুক্ত হবে।)*

### 📱 কীভাবে ফোনে ইনস্টল করবেন:
1. উপরের লিংকে ক্লিক করে **`FotoFilm.apk`** (প্রায় **১২২ MB / ১২০–১২৬ MB**) ডাউনলোড করুন।
2. ডাউনলোড শেষ হলে নোটিফিকেশন বার অথবা ফোনের **Downloads** ফোল্ডারে যান।
3. **`FotoFilm.apk`** ফাইলে চাপ দিন এবং **Install** বাটনে চাপ দিন।
4. যদি ফোনে *Install unknown apps* পারমিশন চায়, তবে **Allow (অনুমতি)** দিয়ে দিন।

### ✨ অ্যাপের প্রধান ফিচারসমূহ:
* **নিউজফিড (Hum) ও পোস্ট:** ছবি, অডিও, রিলস, শর্ট/লং ভিডিও (অটো কম্প্রেশন সহ) এবং রিঅ্যাকশন।
* **ChatFilm (মেসেঞ্জার):** ফিদা এআই, বন্ধুদের সাথে আড্ডা, লুডু কিং গ্রুপ, ভয়েস ও গ্রুপ ভিডিও কল।
* **Shopping Mall ও পেইজ:** পণ্য ক্রয়-বিক্রয়, গ্রিন ভেরিফাইড ব্যাজ (`Fida Verified`) ও মালিকানা সুরক্ষা (`Right Manager Fida`) সিস্টেম।
* **৪টি ভাষা সাপোর্ট:** বাংলা, English, হিন্দি ও আরবি।

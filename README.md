### 📱 কীভাবে ফোনে ইনস্টল করবেন:
1. উপরের লিংকে ক্লিক করে **`FaceFeed.apk`** ডাউনলোড করুন।
2. ডাউনলোড শেষ হলে নোটিফিকেশন বার অথবা ফোনের **Downloads** ফোল্ডারে যান।
3. **`FaceFeed.apk`** ফাইলে চাপ দিন এবং **Install** বাটনে চাপ দিন।
4. যদি ফোনে *Install unknown apps* পারমিশন চায়, তবে Allow (অনুমতি) দিয়ে দিন।

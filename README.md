# FotoFilm - Android Social Networking App 🚀

**FotoFilm** (আগে FaceFeed) একটি আধুনিক সোশ্যাল মিডিয়া, চ্যাট, ভিডিও/অডিও কলিং এবং কমিউনিটি অ্যান্ড্রয়েড অ্যাপ্লিকেশন।

### 📱 কীভাবে ফোনে ইনস্টল করবেন:
1. আপনার ফোনে আগে থেকে **পুরানো `v1.0`** ইনস্টল করা থাকলে *App not installed* সমস্যা এড়াতে সেটি একবার **Uninstall** করুন।
2. উপরের লিংকে ক্লিক করে **`FotoFilm.apk`** (v2.0) ডাউনলোড করুন।
3. ডাউনলোড শেষ হলে নোটিফিকেশন বার অথবা ফোনের **Downloads** ফোল্ডারে যান।
4. **`FotoFilm.apk`** ফাইলে চাপ দিন এবং **Install** বাটনে চাপ দিন।
5. যদি ফোনে *Install unknown apps* পারমিশন চায়, তবে **Allow (অনুমতি)** দিয়ে দিন।

### ✨ অ্যাপের প্রধান ফিচারসমূহ:
* **নিউজফিড (Hum) ও পোস্ট:** ছবি, অডিও, রিলস, শর্ট/লং ভিডিও (অটো কম্প্রেশন সহ) এবং রিঅ্যাকশন।
* **ChatFilm (মেসেঞ্জার):** ফিদা এআই, বন্ধুদের সাথে আড্ডা, লুডু কিং গ্রুপ, ভয়েস ও গ্রুপ ভিডিও কল।
* **Shopping Mall ও পেইজ:** পণ্য ক্রয়-বিক্রয়, গ্রিন ভেরিফাইড ব্যাজ (`Fida Verified`) ও মালিকানা সুরক্ষা (`Right Manager Fida`) সিস্টেম।
* **৪টি ভাষা সাপোর্ট:** বাংলা, English, হিন্দি ও আরবি।
